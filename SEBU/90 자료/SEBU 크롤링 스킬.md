# SEBU 크롤링 스킬

공식 학과 자료의 수집·오타 검수·연구분야 분리와 분류·배포 검증 절차를 [crawling 스킬](<../../.agents/skills/crawling/SKILL.md>)로 공유한다. 이번 실제 검수 결과는 [[SEBU 예체능대학 크롤링 검수 - 2026-10-06]]에서 확인한다.

스킬과 [상세 검수 기준](<../../.agents/skills/crawling/references/2026-10-06-crawling.md>)은 요청 범위에 맞게 재사용하는 작업 지침이다. 과거 출처 수·숫자 ID·마이그레이션 버전을 현재 실행값으로 사용하지 않는다. 실제 작업은 대상 백엔드 체크아웃의 현재 코드와 설정을 확인한 뒤 수행한다.

이 저장소에는 공유할 문서·자료·스킬을 보관한다. 스킬이 존재하거나 문서 검사를 통과했다는 사실은 크롤러 실행·PR 머지·운영 DB 적용 성공을 뜻하지 않는다.

예체능대학 원본·검수 CSV 5개는 이 저장소의 `SEBU/90 자료/data/2026-10-06-crawling/`에 보관한다. 백엔드 검증은 기존 단과대 작업과 같이 DB 건수·대표값·관계·기존 값 보존을 확인하며, CSV 전수 대조용 테스트나 복제 fixture는 남기지 않는다.
