# SEBU 항공우주공학과 링크 보완 기록 - 2026-10-10

**항공우주공학과 교수 소개에서 검증한 홈페이지 12개를 기존 연구실에 보완했고, 운영 API와 서비스 프록시 API에서 반영을 확인했다.** V51을 추가한 핫픽스는 `main`과 `develop`에 모두 병합했다. 연구실을 새로 생성하거나 기존 ID·소속·사용자 콘텐츠를 교체하지 않았다.

이 문서는 2026-10-09 조사·테스트와 2026-10-10 운영 반영 당시의 실행 기록을 정리한 것이다. 이번 문서 갱신에서 배포나 애플리케이션 테스트를 다시 실행했다는 의미는 아니다. 재사용할 절차는 [[SEBU 운영 핫픽스와 데이터 보정]]을 따른다.

## V51의 갱신·보존 조건

`V51__add_missing_aerospace_laboratory_links.sql`은 다음 조건을 모두 만족하는 기존 행만 갱신한다.

1. 교수 이름·이메일과 연구실명이 검수한 대상과 일치한다.
2. 연구실이 삭제되지 않았고 `website_url IS NULL`이다.
3. 교수와 연구실이 **공과대학 내 동일한 허용 학과**에 소속된다. 대표 학과 또는 연결 학과로 소속을 확인할 수 있다.

교수와 연구실이 서로 다른 허용 학과에 각각 속한 것만으로는 갱신하지 않는다. 동일 학과명이 다른 단과대에 있거나 교수·연구실 한쪽만 해당 학과에 속한 경우도 제외한다. 학과 허용 목록은 교수별 검수 결과에 따라 다르다.

변경 컬럼은 `website_url`, `website_url_source=MANUAL`, `updated_at`이다. 숫자 ID를 보정 조건에 고정하지 않으며, 대상이 없는 환경에서는 새 연구실을 만들지 않는다. 기존 URL은 `MANUAL`·`CRAWLED` 여부와 관계없이 유지한다. `MANUAL` 출처는 후속 크롤링 승격에서 검수한 URL을 보존하는 데 사용한다.

기존 V1–V50과 FE 코드는 수정하지 않았다. API 계약도 바꾸지 않았으므로 기존 FE가 내려온 홈페이지 값을 표시하는 흐름을 그대로 사용한다.
