# SEBU 갱신 기록 - 2026-10-09

운영 배포 전 준비에 머물러 있던 브레인을 실제 운영 전환·백업·홈페이지 핫픽스와 최신 FE 코드에 맞춰 갱신했다. 프로젝트 관련 대화는 실행 결과, 팀 방침, 미구현 제안으로 나눠 기존 노트에 연결했다.

## 실제 완료와 남은 일

운영 API와 FE 프록시에서 전체 연구실 622개·물리천문학과 29개·새 홈페이지 14개를 확인했다. 홈페이지가 있는 물리천문학과 연구실은 9개에서 23개로 늘었다. 나머지 6개는 확인된 주소가 없어 추정으로 채우지 않았다. 김경호 교수님의 기존 후기 1개와 실제 상세 화면의 링크 표시도 확인했다.

1시간 절대 만료·5분 전 경고·명시적 연장·세션 만료 모달은 논의한 요구사항이며 현재 완료된 기능이 아니다. 내부 신고 API·관리자 심사, 카테고리 계층 UI, 서버의 동의 이력 저장도 완료로 표시하지 않았다. 실제 학교 로그인과 인증된 작성·수정·삭제의 종단간 수용 검증은 남아 있다. [[SEBU 변경 검토 목록]]

## 검증과 기록 원칙

- 이번 문서 갱신은 원격 Git 커밋과 이미 확보한 운영 실행 기록을 검토했다. 이 문서 작업을 위해 운영 DB를 변경하거나 FE를 수정하지 않았다.
- 핫픽스의 H2/MySQL 44개 테스트와 PR·배포 CI 성공은 기존 실행 결과다. 브레인 검사와 애플리케이션 검증을 혼동하지 않는다.
- 문서 검증은 `npm run sources:record -- --reviewed`, `npm run check`, `npm test`, `npm run sources:check`로 수행한다. 이 도구는 문장 의미나 운영 상태까지 자동 보증하지 않는다.
- 이번 실행에서는 61개 노트·Canvas 1개·164개 출처의 구조 검증, 도구 테스트 5개, 기준 커밋 일치 확인을 통과했다. 로컬 테스트는 샌드박스의 임시 Git 저장소 생성 제한 때문에 일반 실행 환경에서 재실행했다.
- 홈·지식 지도·Canvas·목록·기준 버전을 함께 갱신했다. 과거 날짜 기록과 이전한 원문은 당시 상태를 보존한다.
- 비밀값·실제 환경 파일·회원 데이터·DB 백업·개인 절대 경로는 공유 문서에 포함하지 않는다. 개인 이메일 계정 생성 안내처럼 프로젝트 설계·운영과 관계없는 대화는 제외한다.
