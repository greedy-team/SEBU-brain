# SEBU 물리천문학과 링크 보완 기록 - 2026-10-09

**물리천문학과 기존 연구실 29개 중 비어 있던 홈페이지 14개를 보완했고, 운영 API와 실제 상세 화면에서 반영을 확인했다.** 기존 URL 9개와 미확정 `NULL` 6개를 유지했으며 연구실을 새로 만들거나 기존 ID를 교체하지 않았다. 재사용할 절차는 [[SEBU 운영 핫픽스와 데이터 보정]]에 정리했다.

## 대상과 출처 확인

[본교 물리천문학과 교수소개](https://www.sejong.ac.kr/kor/college/department-of-physics-and-astronomy.do)와 [학과 교수소개](https://dept.sejong.ac.kr/physicsastronomy/intro/professor.do), 개별 페이지의 이름·소속·이메일 등을 대조해 공식 개인 교수 홈페이지 13개를 확인했다. 김경호 교수의 RnDCircle 주소 1개는 사용자가 지정했고 이름·소속을 확인했다.

## V50의 변경 범위

`V50__add_missing_physics_astronomy_laboratory_links.sql`은 교수명·이메일·자연과학대학·물리천문학과·연구실명이 모두 일치하고, 삭제되지 않았으며 홈페이지가 `NULL`인 행만 갱신한다. 변경 컬럼은 URL, `website_url_source=MANUAL`, 수정 시각이다.

숫자 ID를 보정 대상 조건에 고정하지 않아 환경별 ID 차이를 허용하면서 기존 연구실을 유지한다. 대상이 없는 환경에서는 생성하지 않고, URL이 이미 있으면 덮어쓰지 않는다. `MANUAL` 출처는 현재 크롤링 승격 과정에서 검수한 URL을 보존하기 위한 값이다.

로컬 44개 테스트는 14개 대상 각각의 V49→V50 업그레이드, 기존 URL·ID·후기·북마크·연구 분야 보존, 신원·소속·연구실명 불일치와 삭제된 행 제외를 확인했다. 빈 DB의 전체 마이그레이션과 Hibernate 스키마 검증, 적용 후 Flyway 검증, 다시 실행해도 값과 수정 시각이 바뀌지 않는 조건도 포함한다. CI에서는 전체 서비스 테스트와 배포 스크립트 검증, 이미지 빌드 및 MySQL 8.0 기반 운영 이미지 스모크 검사를 수행했다.

`main` 병합 뒤 운영 배포 확인과 `develop` 검증·이미지 게시를 병행했다. 운영 V50은 기존 자동 배포 경로로 반영했으며 운영 DB에 별도 수동 SQL을 실행하지 않았다. 개발 서버는 이 작업을 위해 별도로 시작하지 않았고, 개발 DB는 개발 이미지가 실제 배포될 때 V50을 적용한다.

## 실제 서비스 확인

2026-10-09 **14:38 KST**에 [백엔드 연구실 API](https://api.sebu.kr/api/v1/laboratories)와 [서비스 FE 프록시 연구실 API](https://www.sebu.kr/api/v1/laboratories)를 배포 전 결과와 대조했다.

| 항목 | 백엔드 API | FE 프록시 API |
|---|---:|---:|
| HTTP 상태 | 200 | 200 |
| 전체 연구실 | 622개 유지 | 622개 유지 |
| 물리천문학과 연구실 | 29개 유지 | 29개 유지 |
| 신규 링크 | 14개 모두 일치 | 14개 모두 일치 |
| 보존 대상 URL | 15개 모두 일치 | 15개 모두 일치 |
| 김경호 교수 연구실 후기 | 기존 1개 유지 | 기존 1개 유지 |

29개 연구실의 ID·교수·소속 등 식별 정보도 비교했다. 보존 대상 15개는 기존 URL 9개와 미확정 `NULL` 6개다. 보완 후 URL이 있는 연구실은 23개가 됐다. 후기 수는 당시 관측값으로, 이후 정상적인 사용자 활동에 따라 달라질 수 있다.

Aside에서 실제 서비스의 김경호 교수 연구실 상세 화면을 확인해 **“홈페이지 없음” 대신 RnDCircle 링크가 표시되는 것**까지 확인했다. 다른 모든 링크의 상세 화면을 각각 확인했다는 의미는 아니며, 14개 주소 전체의 운영 반영 근거는 두 API의 비교 결과다.

이번 검증으로 링크 보완 범위를 완료했다. 미확정 6명의 홈페이지 확인과 엄종화 교수 신규 등록 검토는 별도 작업이다.
