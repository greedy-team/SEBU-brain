## 해결된 설명과 남은 차이

- 추천 상세 북마크 미연결과 프로필 훅 인자·저장 캐시 문제는 최신 코드에서 수정됐다.
- 메인 후기 소개는 공통 연구실 API의 실제 reviewCount를 사용한다. 후기 본문이나 별도 최신 후기 API를 조회하는 기능은 아니다.
- 검색어를 비운 뒤 제출하면 keyword가 제거된다. 입력만 지운 상태에서는 아직 적용된 URL 검색어가 남으므로 원래 사용자 시나리오가 모두 자동 해결됐다고 쓰지 않는다.
- parentId는 BE에 반영됐지만 FE가 계층을 사용하지 않는다. 카테고리 목록 API 기반 그룹·부모 선택 시 자식 포함은 후속 과제다.
- 기본 인증 수명은 여전히 Access 30분·Refresh 14일·절대 30일이다. 1시간 고정 만료·경고·연장·만료 모달은 구현된 내용과 구분해 [[SEBU 인증과 CSRF]]에 제안으로 정리했다.
- 개인정보처리방침은 경로와 연결만 있고 본문은 아직 확정 전이다.
