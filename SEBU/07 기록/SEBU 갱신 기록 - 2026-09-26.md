# SEBU 갱신 기록 - 2026-09-26

개인용 초안의 2026-09-23 설명을 최신 팀 브랜치 기준으로 대조하고, SEBU-brain에서 공유 가능한 지식 공간으로 갱신했다.

## 주요 갱신

- 프론트가 Bearer 기반이며 북마크가 미연결이라는 과거 설명을 제거했다.
- 쿠키·CSRF 인증, 북마크 API와 공통 캐시의 실제 연결을 기록했다.
- 검색·단과대·랩실평가 홈이 같은 목록 API와 캐시를 쓰고, 실제 후기 조회·작성은 별도 API임을 정리했다.
- 공개 조회·CORS·사용자 인증의 차이와 Origin 없는 직접 조회의 동작을 별도 노트로 남겼다.
- 로그인 모달·로그인 후 자동 저장은 현재 구현과 구분해 제안으로 남겼다.
- 후기 라우트 활성화와 일반 게시판 라우트 주석 상태를 구분했다.
- 백엔드 prod의 JSON 응답 압축과 상태 확인 경로를 반영했다.
- 개인 절대 경로·개인 노트 의존성을 제거하고 커밋 고정 GitHub 출처를 넣었다.
- clone/Pull 사용법, 검토 후 기준 갱신, 링크 검증과 변경 확인 도구를 추가했다.

## 확인 범위

[[SEBU 저장소와 기준 버전]]의 커밋을 정적으로 대조했다.

- 문서 검사: 노트 37개·Canvas 1개의 링크·경로·근거 관계 통과.
- 원본 비교: 백엔드 develop·프론트 dev의 기준 커밋 일치, 근거 파일 98개 기록.
- 도구 테스트: 새 파일·삭제·이름 변경, 깨진 링크, 근거 기록 등을 검증하는 테스트 5개 통과.
- 이후 변경도 GitHub Actions에서 문서 검사와 도구 테스트를 수행한다.

이번 갱신에서 앱 테스트·배포·실제 학교 로그인은 실행하지 않았다.
