# SEBU AI 도입

SEBU에 **뉴스 기사 요약과 연구실 추천 기능을 도입하려는 계획**을 관리한다. 사용자가 제공한 프로젝트 기획서의 본문·표·그림을 2026-10-26에 읽고 정리했다. 이 영역의 검증 날짜는 원문 확인일이며 기능 개발·배포 완료일이 아니다.

## 도입하려는 기능

이용 조건이 확인된 기사를 수집하고 Gemini API로 한국어 세 문장 요약, 키워드, 관련 연구 분야 ID와 연결 이유를 받는다. 백엔드는 결과를 검증하고 기존 DB의 실제 연구실을 찾아 연결한다. 사용자는 기사에서 연구 분야를 이해한 뒤 연구실 상세 정보와 후기를 탐색한다.

**기사 → 연구 분야 이해 → 교내 연구실 → 기존 후기**를 연결하고, 주기적인 콘텐츠로 재방문할 이유를 만드는 것이 목적이다.

## 갱신 기준

API·DB·모델·수집 주기 등이 확정되면 해당 설계 문서에 결정 내용을 기록한다. 구현 시에는 근거 PR·커밋과 테스트 결과를 추가하고, 운영 반영은 별도의 배포·실행 확인 후 기록한다. FE 화면 구현과 배포는 FE 담당자가 진행한다.
